BFG Unpacker - this is a multifunctional tool for data mining, games research, game modification creation and game translating. With BFG Unpacker you can archives unpacking, archives packing (for few formats), converting multimedia files (video and audio) from many specifical games formats to popular formats, disc images unpacking and converting, converting text from some games to JSON and back, and other. 

### **FEATURES**



* Unpacking archives from lot of games (50.000+, include games on popular engines (Unreal, Unity, Godot and other))
* Converting audio and video from lot of game formats to popular
* Unpacking and converting non-game popular archives format (ZIP, 7Z, RAR and other)
* Unpacking and converting disc images (ISO, BIN\\CUE, ISZ and other)
* Run all BMS scripts
* Converting game text for translating to JSON and back from games on Unreal Engine and Creation Engine
* Creating archives for some games
* Researching file formats (for example, you can use it for detecting packing method for 800+ zipping formats)
* Native support ZIP archive unpacking with almost all possible zipping formats (include even Oodle and other game specific methods)
* Include almost 100 native unpackers writing with Python
* Include 4000+ BMS scripts, witch support 10000+ games
* Include 13 WCX TotalCommander plugins with support 1000+ games and archives formats



WARNING: Python version now in development, and any functions may don't working or working not correctly. For more stability you can use old AutoIt version, however, AutoIt version don't supported any formats from new Python version.



### **SOME HISTORY**



Development of this program started in 2014. Firstly, this was a little UI tool for run any BMS scripts via QuickBMS utility writing in Pascal. It's was bad UI with only tool-menu with alphabet buttons, on witch you can press, to open list of the games on this character.

Second step was rewriting it with normal UI in AutoIt language. It was more usability and see bester then older versions. Why I has been selected AutoIt language? Because this language support easiest instruments for quickly creating user interfaces and can compile in EXE. Latest AutoIt version you can download in download section.

And finally step - I started rewriting it with Python. As UI framework I was selected PyQt with qt\_material plugin. And now, BFG Unpacker working faster, see more usable and is actively developing. 



### **HOW TO USE**



Download recent Python or AutoIt version. Run it.

By first run the program give you select for path, where be place unpacking\\converting files.

You can select game from tree-view list, from upper drop-down menu you can select file types (like archives, disc images, installers or specific formats. Also, you can press quick open button to detecting file type in auto mode (but it working with only some formats, in this moment support detecting \~1000 formats from 4-5k). 

You can change and move imaging buttons in up the program. For it press with right mouse button on any button and be open menu for changing it. 

For multimedia converting press Convertors in upper drop-down menu. You can select options for converting video, audio and images and converting all it in any popular formats.



To run source, download this archive: https://drive.google.com/file/d/1Z\_1q9r-mx-WdNMy0YzNgaUU3B0p2KR-1/view?usp=sharing

And unzip it into data directory
